PUBLIC FINANCE · PANEL DATA

Heterogeneous Effects of Local Government Financing Channels on Industrial Structure

Using provincial panel data from China, this project constructs a data-driven industrial structure index and applies two-way fixed-effects models with robustness checks to examine differences across local government financing channels.

Read project overview

Results. LGFV debt is associated with shifts toward higher-productivity industries, while statutory debt shows the reverse pattern.

Implications. The analysis highlights debt composition, fund allocation, and LGFV transformation as considerations for aligning local financing with regional development needs.

MACHINE LEARNING · POSITIVE–UNLABELED LEARNING

A Two-Stage Positive–Unlabeled Learning Framework for Identifying Undiagnosed Hypertension in Heterogeneous Populations

Using data from 43,105 adults, this project frames undiagnosed hypertension detection as a positive–unlabeled learning problem and develops a two-stage PU-Boost framework to address incomplete diagnostic labels.

Read project overview

Approach. Elastic Net logistic regression and Random Forest reconstruct high-confidence pseudo-labels, followed by XGBoost classification to reduce label contamination in heterogeneous populations.

Results. The model achieved 81.7% sensitivity and 68.2% balanced accuracy. SHAP analysis identified contributing features including age, BMI, waist circumference, and family history.

Read preprint DOI: 10.64898/2026.10.04.26364708
Second authorPreprintPU-Boost · SHAP
03
ECONOMIC THEORY · PLATFORM MARKETS

Self-Sustenance of Market Dominance by Parity Price Clause (PPC): A Motivation from Trip.com

A game-theoretic framework based on Bertrand price competition examines how price parity clauses can sustain market dominance in online travel platforms. Through mathematical propositions, the paper establishes a reinforcing cycle linking market share, consumer information, and PPC enforcement power. Under the model’s assumptions, this mechanism preserves incumbent dominance and raises barriers to competition.
